# Sofia Tooltips ✨

A lightweight, elegant tooltip library for jQuery + Tailwind 4, handcrafted by Sofia and the Monarch 👑

## Install

```bash
npm install sofia-tooltips
```

## Usage

```javascript
import $ from 'jquery';
import initSofiaTooltip from 'sofia-tooltips';

initSofiaTooltip($);
```

Add tooltips to any element:

```html
<button data-tooltip="Hello World!" data-tooltip-position="top">Hover Me</button>
```

For full options, see the library docblock!
